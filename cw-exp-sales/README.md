# 店舗売上CSV → Excel集計ツール

Windows 11向けの、画面操作のない小さなPythonツールです。複数の売上CSVを読み込み、`数量 × 単価` で売上金額を計算します。元のCSVは読み取り専用で開くため、変更・削除しません。

## 1. 最初の準備

1. [Python公式サイト](https://www.python.org/downloads/windows/)から Python 3.11以降をインストールします。インストーラーの **Add python.exe to PATH** にチェックを入れてください。
2. この `cw-exp-sales` フォルダーをWindows上に用意します。
3. エクスプローラーでこのフォルダーを開き、アドレス欄に `cmd` と入力してEnterキーを押します。
4. 開いた画面で次を実行し、必要な部品をインストールします（初回のみ、インターネット接続が必要です）。

   ```bat
   python -m pip install -r requirements.txt
   ```

## 2. 毎月の使い方

1. `input_csv` フォルダーに、その月に集計したいCSVだけを入れます。最初から入っている3つのCSVは動作確認用です。実際の集計時はサンプルを別の場所に保管し、対象月のCSVだけを用意してください。
2. `run.bat` をダブルクリックします。
3. 「集計が完了しました！」と表示されたら、`output` フォルダーの `売上集計.xlsx` を開きます。
4. 結果の画面はEnterキーを押すと閉じます。

出力は実行するたびに同じExcelファイルを上書きします。前月分を残したい場合は、先にExcelのコピーを別名で保存してください。実行前に `売上集計.xlsx` をExcelで閉じてください。

## CSVの書き方

列の順番は `日付,店舗名,商品名,数量,単価` の5列です。見出しはあってもなくてもかまいません。最初の空でない行がこの5つの列名と一致すると、見出しとして自動判定します。

```csv
日付,店舗名,商品名,数量,単価
2026/10/01,草津店,商品A,2,500
2026/10/01,大津店,商品B,1,1200
2026/10/02,草津店,商品B,3,1200
```

- 文字コードはUTF-8（BOMあり・なし）を先に試し、読めなければCP932（Windowsの日本語CSV）を試します。
- 数量・単価には半角の数値を使います。小数や負数も使えます。`円` や桁区切りのカンマは付けないでください。金額は端数を丸めずに計算します（小数は浮動小数点で扱います）。
- 日付は入力の文字列のまま保存します。店舗名・商品名も文字列として保存し、各項目の前後の空白は取り除きます。
- 同じ行が複数のCSVにあれば、その回数分を集計します。日付による月の絞り込みや重複削除は行いません。
- フォルダー直下の `*.csv` が対象です。サブフォルダーは読みません。
- 空のファイル、見出しだけのファイル、読み取れないファイルは、日本語の警告を出してスキップします。
- 数量・単価が不正な行（空欄、文字、NaN、無限大など）、列数が違う行、日付・店舗名・商品名が空欄の行も、ファイル名と行番号を表示してスキップします。他の有効な行は集計を続けます。
- CSVの引用符が壊れている場合は、そのファイル全体をスキップします。
- 有効なデータが1件もなければExcelを作成・更新せず、終了コード1で終了します。集計できた場合は終了コード0です。警告があれば、スキップされたデータを確認してください。

## 作成されるExcel

保存先は常に **`main.py` と同じフォルダー内の `output/売上集計.xlsx`** です。`output` がなければ自動で作ります。

| シート | 内容 |
| --- | --- |
| 明細 | 日付、店舗名、商品名、数量、単価、売上金額 |
| 店舗別合計 | 店舗名、売上合計 |

付属サンプルは9件で、草津店5,900円、大津店5,600円、彦根店3,100円、全店合計14,600円です。`output/売上集計.xlsx` にはこのサンプルの集計結果を同梱しています。

## 別のフォルダーを指定する場合

コマンド画面では、最初の引数にCSVフォルダーを指定できます。パスに空白がある場合は `"` で囲んでください。

```bat
python main.py "C:\売上データ\2026年10月"
run.bat "C:\売上データ\2026年10月"
python main.py "input_csv"
```

省略時は `main.py` の隣の `input_csv` を使います。相対パスも、コマンドを実行した場所ではなく `main.py` の場所を基準にします。別の場所からは `python "C:\ツール\cw-exp-sales\main.py" "input_csv"` のように指定できます。入力先を変えても、出力先は同じです。

`python main.py` の直接実行や、引数付きの `run.bat` は、最後にEnterキーを待ちません。

## 困ったとき

- **Pythonが見つからない:** PythonのPATH設定を確認し、コマンド画面を開き直してください。Microsoft Storeが開く場合はPythonのインストールを確認してください。
- **必要な部品が見つからない:** このフォルダーで `python -m pip install -r requirements.txt` を実行してください。
- **Excelに保存できない:** Excelで開いている集計ファイルを閉じ、保存先のアクセス権と空き容量を確認してください。
- **警告が出る:** 画面に表示されたファイル・行を確認してください。元のCSVはこのツールから書き換えません。

## 動作確認

```bat
python run_test.py
```

サンプルCSVの集計、2つのシート・全明細・店舗別合計、元CSVのSHA-256が実行前後で同じことをassertで確認します。さらに一時フォルダーで文字コード、見出しの有無、空ファイル、読み取り失敗、不正な数値、別の起動場所、相対・絶対パスなどを確認します。

テストはサンプルのExcelを `output/売上集計.xlsx` に作成・上書きします。付属のサンプルCSV3個を変更せずに実行してください。実施したテストの記録は `TEST_RESULT.md` にあります。
