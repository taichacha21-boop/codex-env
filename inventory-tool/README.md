# 商品マスタ × 入出庫 CSV 在庫更新ツール

添付仕様 `final_spec.md` に基づく、Windows 11 向け Python デスクトップツールです。マスタと複数 CSV を読み、在庫・集計・処理履歴・エラー一覧・警告一覧を含む **別の Excel** を作成します。

入力 Excel / CSV への保存・削除は行いません。同一キーの内容矛盾、マスタ内コード重複、継続時の履歴不備は実行全体を停止します。

## 必要環境と準備

- Python 3.12（自動テスト: 3.12.14）。Windows 版 Python のインストール時に Tcl/Tk を含めてください。
- ライブラリ: `openpyxl==3.1.5`、`et_xmlfile==2.0.0`。テストは標準ライブラリの `unittest` を使います。
- **Windows 11 実機・GUI・run.bat は未検証**です。Linux 上の検証結果は `TEST_RESULT.md` を参照してください。仕様18の本番納品条件である Win11 実機検証は未充足です。

このフォルダでコマンドプロンプトを開き、初回のみ実行します。

```bat
py -3 -m pip install -r requirements.txt
```

`py` がない場合は `python` に置き換えます。その後 `run.bat` をダブルクリックしてください。コマンドからは `py -3 main.py` でも起動できます。

## 操作

1. **初回 / 継続を明示選択**します。自動判定・初期選択はありません。
2. マスタ Excel を選択します。
3. CSV フォルダを選択します。
4. 「実行」を押し、完了画面と各一覧を確認します。

初回は「処理履歴」のないオリジナルマスタを指定します。継続では **前回の更新結果 Excel** を指定します。履歴のあるマスタを初回で取り込むことも拒否し、履歴の破棄による二重反映を防ぎます。履歴がない場合に継続から初回へ切り替えることはありません。

結果は入力マスタと同じフォルダに保存します。命名は端末ローカル日時の `商品マスタ_更新結果_YYYYMMDD_HHMMSS.xlsx` に固定しています。同名があれば `_001`、`_002` …を付け、既存ファイルを上書きしません。保存先フォルダに新規作成権限が必要です。

## 入力

### マスタ

- `.xlsx` 形式、シート名 **商品マスタ**。1行目が見出しです。
- 必須列は **商品コード / 商品名 / 現在庫**。列順は任意で、重複した必須見出しは使用できません。
- 単価は任意で、存在する場合は値・書式を変更しません。他列・他シートも保持します。
- 現在庫は有限の数値セルを使用します。文字列の `"100"`、空欄などはマスタ行エラーです。当該商品への取引も除外します。他の正常商品は処理できます。
- 現在庫が数式の場合、当該商品は未更新とし警告します。**配列数式の定義範囲内も対象外**です。アンカーが現在庫列以外にある場合や、範囲内の現在庫セルが数値・空欄の場合も更新しません。取引がない数式商品も、マスタのファイル名と行番号を付けて警告します。数式・定義範囲・範囲内の値を保持し、評価・変更しません。
- 商品コードは文字列として照合・出力します。前後空白は除去します。例えば `00125`、正式コード `00408` はそのまま保持します。数値セルの `408` は文字列 `408` とし、表示形式が `00000` でも `00408` を推測しません。元データで失われたゼロは復元できません。

### CSV

- 指定フォルダ**直下**の `.csv` / `.CSV` 全ファイルをファイル名順に読みます。サブフォルダは対象外です。
- カンマ区切り、1行目が見出し。引用符付きカンマ・改行に対応します。
- 文字コードは **UTF-8（BOMあり / なし）** を最初に試し、デコードできない場合は **CP932** を使います。両方を自動テスト済みです。
- 必須列: **伝票番号 / 明細ID / 日付 / 商品コード / 区分 / 数量**。列順は任意、その他の列は読み飛ばします。`日付` の代わりに `日時` も使用できますが、両方の同時指定・同名必須見出しの重複は停止します。
- 日付: `YYYY-MM-DD` / `YYYY/MM/DD`。時刻を含める場合は空白または `T` に続けて `HH:MM` / `HH:MM:SS`（小数秒は最大6桁）を指定できます。タイムゾーン付き日時や月日年の順は対象外です。存在しない日付はエラーです。
- 数量は **1～999999999999999（15桁以内）** の半角数字の整数です。Excelとopenpyxlで整数を正確に保持するため、上限超過は行エラーとして在庫・履歴の対象から除外します。`0`、負数、小数、`1.0`、全角数字、符号付き数量もエラーです。区分は **入庫 / 出庫** のみです。
- 計算に用いる現在庫・今回入庫・今回出庫・処理後在庫の絶対値も **999999999999999以下** に制限します。各数量が上限内でも合計や計算結果が範囲を超える場合は、丸めて保存せず実行全体を停止します。
- 空のレコードは読み飛ばします。欠損・列数不一致は行エラーです。必須見出し不足、読取不能、引用符の破損、空ファイル、CSVなしは全体停止します。

## 重複・矛盾・履歴

キーは **伝票番号＋明細ID** の2項目です。今回の全CSVと、継続時の処理履歴の両方を照合します。同一キー・同一内容は1回分だけ反映します。商品コード・区分・数量・日付のどれかが異なる場合は、正常な別行も含め **全件未反映で停止**します。不正行でもキーが揃っていれば矛盾照合の対象です。

伝票番号・明細IDは、前後空白を除いた値が **それぞれ32767文字以内** である必要があります。Excelのセル長上限を超えるCSV行はエラーとして除外し、切り詰めません。継続履歴に上限超過のキーや上記数量上限を超える値がある場合は、履歴不備として実行全体を停止します。

照合時には前後空白を除去し、数量は整数値、日付は同じ日付・時刻に正規化します。`2026/10/01`、`2026-10-01`、同日の午前0時は同一です。異なる時刻は別内容として矛盾になります。商品コード自体を変換・補完しません。

`処理履歴` は1行目に **伝票番号 / 明細ID / 日付 / 商品コード / 区分 / 数量 / 処理日時** が必要です。継続時は必須列・各値・重複キーを検証し、不備があれば自動修復せず停止します。履歴内の同一キーは内容が同じでも異常として停止します。履歴のコードは文字列が必須です。

新規履歴に入れるのは今回実際に在庫へ反映した行だけです。行エラー・数式除外行は履歴に入れません。修正後に再取込できます。履歴を含む完成 Workbook をメモリ上で構築し、**Workbook の保存を1回だけ**行ってから完成バイト列を公開します。保存後に履歴だけ追記・再保存することはありません。

## 結果と一覧

- 元シートの順序・列順・見出し・列幅・基本セル書式・既存数式を保持します。元の `商品マスタ` はコードを文字列化し、正常な数値の現在庫だけ更新します。
- 集計: **商品コード / 商品名 / 現在庫 / 今回入庫 / 今回出庫 / 処理後在庫 / 備考**。現在庫は今回処理前の値です。入出庫は今回実際に反映した数量です。
- 数式商品も集計に表示します。入出庫は0、在庫は元の数式を**文字列**として表示し、備考に **現在庫が数式のため未更新** と記載します。配列範囲内のセルにはアンカーの数式文字列を表示します。数式オブジェクトを集計へコピーせず、集計上で数式の評価は行いません。
- `エラー一覧`: 未登録商品・欠損・不正値等。`警告一覧`: 数式現在庫・負在庫。どちらも **元ファイル名 / 行番号 / 内容** を別シートに出力します。CSVはヘッダを含む物理行番号（改行を含むレコードは開始行）、マスタはExcel行番号です。ファイル全体の問題は行番号0とします。
- 負在庫はそのまま計算・履歴登録し、自動補正しません。処理後が負の商品の反映行ごとに警告します。今回反映がなく既に負の場合はマスタの行を示します。
- 既存の `集計` / `エラー一覧` / `警告一覧` は変更しません。同名がある場合、今回分を `集計_2`、`エラー一覧_2` …として末尾に追加し、画面に今回のシート名を表示します。`処理履歴` は既存シートに追記します。
- 全体停止時は結果 Excel を作成せず、画面にエラー・警告を分けて表示します。行単位エラーだけの場合は、正常行を反映した結果 Excel を作成します。

完成バイト列を保存先と同じフォルダの一時ファイルに書き、書込完了後に排他的に公開します。Windows は既存宛先を上書きしない rename、Linux は既存宛先を上書きしない hard link を使用します。結果名の競合も連番で再試行します。失敗時は処理完了・履歴登録とは扱いません。一時ファイルの削除も失敗した場合は、残ったパスをエラーに明示します。入力マスタへ履歴を書き込むことはありません。

## テストとサンプル

```bat
py -3 run_test.py
```

Linux では `python run_test.py` です。テストは一時フォルダ上で実行し、同梱サンプルに結果を書き込みません。実行結果・実行環境は `TEST_RESULT.md`、サンプルの期待値は `sample_data/README.md` にあります。

`sample_data/master.xlsx` と `sample_data/normal/` で正常例を試せます。実データとの混同を避けるため、試行にはサンプルを任意の作業フォルダへコピーしてください。

## 制限・未検証事項

- Excel自身による数式再計算や数式の評価済みキャッシュ保持は行いません。既存の数式文字列は保持します。結果の表示はExcelの再計算設定に依存します。
- `.xls` / `.xlsm`、マクロの改修、Web化、クラウド同期、会計処理などは対象外です。
- openpyxlで扱える基本書式を対象とします。サンプルの列幅・行高・基本書式・テーブル・他シートの結合セル・非表示シート・既存数式の保持を自動検証しています。依頼者実データの複雑な書式、在庫表内の結合セル、保護シート、図形・外部機能の完全保持は未検証です。
- Windows 11 の実機操作、ファイルロック、ネットワーク共有上での保存は未検証です。Linuxの保存先はhard link対応ファイルシステムが必要です。非対応の保存先ではエラー停止します。
- 実案件の匿名化 Excel / CSV は未提供です。同梱サンプルで確認した入力形式を記載しています。本番採用前には実入力形式およびWin11実機での確認が必要です。
