# サンプルと期待値

`master.xlsx` の初期在庫は `00125: 100`、`00408: 20`、`00999: 2` です。商品Bの正式コードは文字列 `00408` です。

| CSVフォルダ | 入力マスタ | 初回の期待値 |
| --- | --- | --- |
| `normal/` | `master.xlsx` | 4行反映。00125=107、00408=18、00999=2。エラー・警告0。UTF-8 BOMあり / CP932の2ファイル |
| `duplicate/` | `master.xlsx` | 同一キー・同一内容を2行除外、2行反映。00125=110、00408=16、00999=2 |
| `conflict/` | `master.xlsx` | 同一キーで数量が矛盾。全体停止、結果なし、在庫反映0 |
| `errors/` | `master.xlsx` | 明細ID空欄・未登録・コード408・数量不正・日付不正・区分不正・欠損を除外。エラー10件、正常1行のみ反映。00125=102、00408=20、00999=2 |
| `warnings/` | `master_formula.xlsx` | 数式F001の取引は除外・履歴なし。00999は-3、履歴1行。数式・負在庫の警告各1件、エラー0 |
| `missing_header/` | `master.xlsx` | 明細ID見出しなしで全体停止、結果なし |
| `normal/` | `master_duplicate.xlsx` | マスタコード00125重複で全体停止、結果なし |

継続の確認は、まず `normal/` を初回処理し、その**更新結果**を継続モードのマスタとして同じ `normal/` を再取込します。反映0、重複除外4、在庫・履歴は前回と同じです。履歴のない `master.xlsx` を継続で指定すると停止します。

サンプルを作業フォルダにコピーして利用してください。入力自体は変更されませんが、GUI実行時の結果は選択したマスタと同じフォルダに作成されます。自動テストは一時フォルダへのコピーを使います。
